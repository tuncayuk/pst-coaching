## Notlar

### Design System Gereksinimleri

1. **Renk Paleti:** Primary, Secondary, Accent, Semantic (Success, Warning, Error, Info)
2. **Typography:** Heading 1-6, Body, Caption, Button text
3. **Spacing:** 4px grid system
4. **Shadows:** 3 elevation levels
5. **Border Radius:** 4px, 8px, 12px, 16px, Full
6. **Icons:** Consistent icon set (Lucide, SF Symbols, Material)

### Erişilebilirlik Gereksinimleri

1. Minimum touch target: 44x44 pt
2. Contrast ratio: WCAG 2.1 AA (4.5:1 text, 3:1 UI)
3. Focus indicators for keyboard navigation
4. Screen reader labels for all interactive elements
5. Reduced motion option

### Platform Farklılıkları

| Özellik | iOS | Android |
|---------|-----|---------|
| Navigation | Bottom Tab Bar | Bottom Navigation |
| Back Button | Swipe gesture, Header | System back, Header |
| Modals | iOS-style sheets | Material bottom sheets |
| Alerts | UIAlertController | MaterialAlertDialog |
