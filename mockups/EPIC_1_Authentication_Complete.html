US-1.1: Splash & Onboarding
🎨 Splash Screen 7 ACs
✓ Acceptance Criteria
  • Display PST logo prominently
  • Show brand colors and tagline
  • Display loading indicator
  • Auto-transition after 2-3 seconds
  • Check authentication status
  • Route to onboarding or home
  • Handle offline state gracefully
👋 Onboarding 10 ACs
✓ Acceptance Criteria
  • 3 screens with swipe gesture
  • Visual illustrations per screen
  • Clear title and description
  • Progress dots indicator (1/3, 2/3, 3/3)
  • Skip button on all screens
  • Next/İleri button
  • Final screen: Başla button
  • Only show once per install
  • Smooth animations
  • Accessibility support
US-1.2: Login
🔐 Login 12 ACs
✓ Acceptance Criteria
  • Email/phone input field
  • Password with show/hide toggle
  • Remember me checkbox
  • Login button (disabled until valid)
  • Forgot password link
  • Social login (Google/Apple)
  • Sign up link
  • Email/phone validation
  • Password min 8 chars
  • Show error messages
  • Loading state during auth
  • Redirect to home on success
US-1.3: Register
📝 Register 15 ACs
✓ Acceptance Criteria
  • Full name input field
  • Email with validation
  • Phone with country code
  • Password (min 8 chars)
  • Confirm password field
  • Password strength indicator
  • Terms & conditions checkbox
  • Privacy policy checkbox
  • Register button
  • Social registration options
  • Validate before submit
  • Show specific errors
  • Check password match
  • Email uniqueness check
  • Send verification code

US-1.9 & US-1.10: New Features
📊 Demographics 7 ACs NEW
✓ Acceptance Criteria
  • İlk kez içerik başlatmadan önce yaş/cinsiyet/ülke formu açılır

  • Yaş alanı zorunlu ve 13-120 aralığında doğrulanır

  • Ülke alanı zorunlu ve arama ile seçilebilir

  • Daha önce kaydedilmişse tekrar sorulmaz
